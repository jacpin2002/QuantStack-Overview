## Overview

QuantStack is a production-grade multi-agent AI system for autonomous quantitative trading research and execution. It runs continuously on a live server, operating across the full research-to-execution pipeline without human intervention.

The system is powered by the Anthropic Claude SDK as its core reasoning engine.
